# Spec: 规则管理页面优化

**Status**: approved
**Created**: 2026-05-25

## 背景

当前规则管理页面使用表格布局，在移动端存在以下问题：
1. **查看困难**：表格列数多，内容被压缩，匹配条件和分类信息不够直观
2. **修改不便**：编辑规则需要弹出表单弹窗，无法快速修改
3. **错误检测弱**：冲突检测仅限于相同关键词对应不同分类，缺少对冗余规则、无效分类的检测

## 需求

### 1. 卡片式规则列表
- 每条规则以卡片形式展示，清晰显示：规则名称、匹配逻辑（字段+方式+关键词）、目标分类、优先级
- 匹配逻辑用可视化方式呈现，如：「商户/对方 包含 [关键词] → [分类图标+名称]」
- 按优先级从高到低排序

### 2. 增强的错误/冲突检测
- **规则冲突**：相同关键词+相同匹配字段→不同分类（原有）
- **冗余规则**：相同关键词+相同匹配字段+相同分类（完全重复）
- **无效分类**：规则关联的分类已被删除
- 顶部汇总面板显示：总规则数、冲突数、冗余数、无效数
- 有问题规则的卡片高亮显示对应警告

### 3. 快速编辑
- 卡片上有编辑按钮，弹出编辑表单
- 支持优先级快速调整（卡片上的 +/- 按钮）
- 支持快速启用/禁用规则（toggle switch）

### 4. 规则搜索/筛选
- 顶部搜索框可按关键词、规则名称搜索
- 按匹配字段筛选（商户/对方、原始分类、备注）
- 按分类筛选

### 5. 规则测试功能
- 提供输入框，输入文本后显示哪些规则会匹配这条文本
- 帮助验证规则是否正确配置

## 约束
- 移动端优先，最大宽度 480px
- 单页 HTML 应用，CSS/JS 内嵌
- 保持现有规则数据结构不变：`{ id, name, field, matchType, keyword, categoryId, priority }`
- 保持现有自动分类逻辑不变

## 验收标准
- [ ] 规则列表以卡片形式展示，包含完整匹配逻辑信息
- [ ] 顶部汇总面板显示规则统计和问题数量
- [ ] 冲突/冗余/无效分类规则在卡片上有明显警告标识
- [ ] 搜索框可实时过滤规则列表
- [ ] 规则测试功能可输入文本并显示匹配结果
- [ ] 优先级可通过卡片上的 +/- 按钮快速调整
- [ ] 所有现有规则功能（添加、编辑、删除、批量删除）正常工作
