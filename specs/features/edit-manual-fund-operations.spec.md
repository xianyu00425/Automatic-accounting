# Spec: 账单编辑与手动记账操作类型扩展

**Status**: implemented
**Created**: 2026-04-20

## 背景

在"待处理账单"处理弹窗中已实现借入/借出/还款/收款功能。现在需要将此功能扩展到账单列表的编辑详情弹窗和手动记账弹窗，并在选择资金变动类型时自动绑定导入时勾选的账户。

## 需求

### 账单编辑弹窗
- `edit-type` select 新增借入/借出/还款/收款 4 个选项
- 新增对应的账户选择器字段（钱包+应付/应收）
- 打开编辑弹窗时，将导入时勾选的账户（`t.accountId`）作为钱包默认值
- 保存时生成/更新配对交易记录

### 手动记账弹窗
- `add-type` select 新增借入/借出/还款/收款 4 个选项
- 新增对应的账户选择器字段
- 保存时生成 2 条交易记录（应付/应收+钱包）

### 账户绑定逻辑
- 编辑场景：原有交易的 `accountId` 带入作为钱包默认选择
- 手动记账：用户手动选择钱包和应付/应收账户

## 实现变更

### HTML
- `edit-type` / `add-type` 各新增 4 个 option
- 编辑弹窗新增 8 个账户选择器字段
- 手动记账弹窗新增 8 个账户选择器字段

### JS
- `toggleEditTypeFields()` — 新增 4 种类型的字段显隐逻辑
- `saveEditTransaction()` — 新增 4 种类型的保存逻辑，处理配对记录清理
- `toggleAddTypeFields()` — 新增 4 种类型的字段显隐逻辑
- `saveAddTransaction()` — 新增 4 种类型的保存逻辑
- `showEditTransactionModal()` — 预填充账户选择器，绑定原账户
- `showAddTransactionModal()` — 预填充账户选择器

## 验收标准
- [x] 编辑账单弹窗可选择借入/借出/还款/收款
- [x] 手动记账弹窗可选择借入/借出/还款/收款
- [x] 编辑时原账户作为钱包默认值
- [x] 保存后账户余额正确更新
- [x] 交易记录正确生成
